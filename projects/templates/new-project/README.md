# Research Project Template

Use this directory structure when creating a new research project in this repository.

## Recommended Layout

* `docs/`: White papers, formal specifications, literature reviews, and design notes.
* `src/`: Clean, modular reference implementations of proposed algorithms, models, or architectures.
* `benchmarks/`: Automated stress tests, empirical comparison scripts, and evaluation metrics.
* `tests/`: Unit and integration tests.
* `README.md`: High-level summary of the thesis, methodology, and instructions for reproducing results.
